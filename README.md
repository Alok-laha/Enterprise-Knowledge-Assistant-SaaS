# Enterprise Knowledge Assistant

A multi-tenant SaaS application powered by
Amazon Bedrock and RAG.

## Features

- Multi-tenant architecture
- Document upload
- AI-powered document retrieval
- Conversational question answering
- Source citations
- Tenant-level data isolation

## Tech Stack

- Next.js
- Python FastAPI
- PostgreSQL
- Amazon Bedrock
- Amazon S3
- AWS Cognito
